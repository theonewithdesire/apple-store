# Apple Store Data Explorer

A web-based application that visualizes and explores Apple App Store data. Built with HTML, CSS, and JavaScript, this project provides an intuitive interface to browse and analyze iOS applications.

## 🚀 Quick Start

1. Clone this repository
2. Run the Python server:
   ```bash
   python3 server.py
   ```
3. Open http://localhost:8000 in your browser

## 📱 Features

- **App Browser**: Browse through thousands of iOS apps with their ratings, prices, and genres
- **Search**: Instantly find apps by name or genre
- **Detailed View**: Click on any app to see its complete information
- **Responsive Design**: Works seamlessly on desktop and mobile devices

## 🗂 Project Structure

- `index.html` - Main application page
- `app-detail.html` - Detailed view for individual apps
- `styles.css` - All styling and responsive design
- `script.js` - Main application logic
- `app-detail.js` - Detail view functionality
- `AppleStore.csv` - Dataset containing app information
- `server.py` - Simple Python server for local development

## 💻 Technology

- Pure HTML5, CSS3, and JavaScript (ES6+)
- Python HTTP server for local development
- CSV data processing for app information
- Responsive design using CSS Grid and Flexbox

## 📊 Data Source

The application uses the Apple Store dataset (`AppleStore.csv`) containing information about thousands of iOS applications, including:

- App names and descriptions
- Ratings and review counts
- Prices and genres
- Content ratings
- Languages supported
